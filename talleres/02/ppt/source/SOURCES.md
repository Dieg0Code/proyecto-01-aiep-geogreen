# Fuentes de imágenes - Taller 02

Imágenes usadas como base visual del PPT del Taller 2. Se guardan localmente en
`assets/images/` para que el deck pueda reconstruirse sin depender de la red.

Criterio: priorizar contexto chileno (puntos limpios, convención de colores de
reciclaje de Chile) cuando la imagen muestre contenedores o escenas de reciclaje.
