# Banco visual — Taller 04

Este directorio contiene la selección curada para construir el PPT del Taller 4. La existencia de un archivo aquí no obliga a usarlo: el guion visual define qué recurso cumple una función narrativa concreta.

## Estructura

- `propias/`: fotografías, interfaces y resultados de GeoGreen, Aula Subtitulada y Ataxx/NÉMESIS.
- `oficiales/openai-hf/`: imágenes y PDF publicados por OpenAI o Hugging Face sobre el incidente.
- `referencias/`: capturas de páginas, charla Black Hat y Artificial Analysis.
- `generadas/`: tres ilustraciones creadas específicamente para conceptos abstractos.
- `marca/`: logos AIEP y marcas auxiliares para atribución visual puntual.

## Criterios de uso

- Priorizar material real antes que ilustraciones generadas.
- Mantener visible la fecha **30 de agosto de 2026** cuando se muestre la captura de Artificial Analysis, porque el ranking cambia.
- Usar las figuras del informe técnico para explicar, no para llenar espacio.
- No presentar Aula Subtitulada como un servicio desplegado en producción: es un prototipo funcional.
- No convertir el incidente en estética de “hacker con capucha”; el interés está en la coordinación emergente, el *reward hacking* y los límites del sistema.
- Toda imagen externa debe conservar una atribución breve en la propia diapositiva y una entrada completa en `SOURCES.md`.
