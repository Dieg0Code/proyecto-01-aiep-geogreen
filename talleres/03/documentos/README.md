# Documentos del Taller 3

## Material vigente

- `taller-3-planificacion-docente.pdf` — planificación de la sesión de 90 minutos, con mediación,
  seguridad, evaluación formativa y continuidad.
- `taller-3-ficha-propuesta-tecnologica.pdf` — ficha imprimible de cuatro páginas para la salida
  obligatoria de cada equipo.
- `taller-3-leeme-docentes.pdf` — guía rápida de ejecución y lectura del paquete.

Los archivos `.tex` son las fuentes editables de estos documentos.

## Material histórico

- `guia-taller-3-arduino-sensores.pdf`
- `kits-taller-3-geogreen.pdf`

Estos dos documentos corresponden a una formulación anterior del taller, centrada en ejercicios
lineales de electrónica y en una especificación preliminar de kits. Se conservan como antecedente,
pero **no forman parte del paquete vigente**. La referencia metodológica actual es
[`../README.md`](../README.md).
