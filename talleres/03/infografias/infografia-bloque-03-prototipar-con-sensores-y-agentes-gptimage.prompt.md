# Prompt — Infografía Taller 3 · Bloque 3

- Audiencia: estudiantes de tercero medio trabajando en equipos de seis.
- Propósito: enseñar cómo convertir un problema en una primera prueba segura con apoyo de agentes, manteniendo las decisiones y la verificación en el equipo humano.
- Formato: vertical largo 1024 × 1536, WhatsApp-first.

```text
Use case: infographic-diagram.
Create an engaging, premium Spanish educational infographic for teenagers, portrait 2:3, optimized for WhatsApp. VIBE AIEP · SIN LOGOS.

Visual style: contemporary STEM editorial infographic, warm cream #F8F3EC, deep navy #102A43, red #D62027 as a restrained accent, ink #243B53, teal highlights, white cards with thin borders, crisp vector-like illustrations, subtle circuit traces and generous space. Dynamic enough to hold teenage attention, but precise and professional for teachers and stakeholders. No logos, no watermark, no fake chat screenshots.

Composition: header; a large problem-to-sensor visual funnel; a central agentic workflow; a split human/agent responsibility card; a small-test evidence panel; one teamwork badge; bold footer.

TEXT — reproduce exactly in Spanish:
Small label: "TALLER 3 · BLOQUE 3"
Main title: "PROTOTIPAR CON SENSORES Y AGENTES"
Subtitle: "La IA acelera; el equipo decide y verifica"

Funnel title: "Primero, define qué observar"
Funnel flow: "PROBLEMA → VARIABLE → SENSOR"
Examples: "Llenado → distancia → HC-SR04"; "Riego → humedad → Soil"; "Luz encendida → luminosidad → KY-018"

Workflow title: "Dirige al agente con contexto"
Workflow: "INTENCIÓN → CONTEXTO → PREGUNTAS → PLAN → PRUEBA → EVIDENCIA"

Agent card title: "EL AGENTE PUEDE"
Agent card items: "Investigar"; "Explicar"; "Proponer pasos"; "Ayudar con código"
Human card title: "EL EQUIPO DEBE"
Human card items: "Elegir"; "Verificar"; "Probar"; "Decidir la mejora"

Test title: "La primera prueba es pequeña"
Test questions: "¿Cambia la lectura?"; "¿Responde una salida?"; "¿Qué evidencia guardamos?"

Team badge: "6 roles · 1 propuesta compartida"
Footer: "Empieza pequeño · prueba · registra · mejora"

Visual direction: show a student team starting from an environmental situation and narrowing it into an observable variable and a real sensor. The workflow should be the visual protagonist, rendered as six connected stations moving from a purpose icon to a context card, question bubbles, a plan, a tiny safe circuit test and an evidence checkmark/photo. The responsibility card should show an AI assistant on one side and human students with a magnifying glass/checklist on the other, balanced rather than adversarial. The small test panel shows one sensor reading changing and then a single LED reacting. Avoid displaying repository commands or completed project code.

Constraints: Spanish only, correct accents and exact wording. No prompt templates, no command line commands, no meta commentary, no claim that mentors will build the project, no logos. Keep text large and uncluttered.
```
