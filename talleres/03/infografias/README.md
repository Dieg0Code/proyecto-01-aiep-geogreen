# Taller 3 · Infografías

Infografías asociadas al Taller 3.

## Mapa general

- `taller-3-mapa-de-la-clase.png` — recorrido completo de los 90 minutos, salida obligatoria y
  continuidad posterior; también se conserva en PDF. La fuente editable es
  `taller-3-mapa-de-la-clase.tex`.

## Serie por bloques

Láminas verticales para lectura en teléfono, generadas como una familia visual continua. Cada PNG
conserva a su lado el prompt reproducible utilizado para generarlo.

- `infografia-bloque-01-una-idea-puede-crecer-gptimage.png` — GeoGreen como ruta de innovación y
  apertura del desafío de los equipos.
- `infografia-bloque-02-del-mundo-fisico-al-dato-gptimage.png` — placa, sensor, protoboard,
  conexiones y protocolo previo al USB.
- `infografia-bloque-03-prototipar-con-sensores-y-agentes-gptimage.png` — problema, variable,
  sensor, flujo agéntico, verificación humana y primera evidencia.
- `infografia-bloque-04-del-prototipo-al-producto-gptimage.png` — madurez, software, diseño 3D,
  PCB y continuidad hacia las mentorías y el evento final.

Las cuatro láminas están dirigidas primero a estudiantes de tercero medio, con una redacción y
estructura suficientemente claras para docentes y stakeholders del proyecto.

Destacadas para la clase (electrónica → programación → flujo agéntico):

- `infografia-programar-en-arduino.jpg` — lo básico de Arduino: `setup`/`loop`,
  `pinMode`/`digitalWrite`/`analogRead`, entradas/salidas, control de flujo, errores comunes.
- `infografia-flujos-agenticos-arduino-iot.jpg` — metodología para investigar/simular/programar
  con IA + las herramientas del repo (PlatformIO, Wokwi, skills, comandos CLI).
