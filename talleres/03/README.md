# Taller 3 · Tecnología y prototipado

Carpeta para materiales del Taller 3.

Foco previsto: Arduino, sensores, actuadores, simulación y GeoGreen como caso demostrativo para que cada equipo defina una idea tecnológica inicial.

## Documentos

- `documentos/guia-taller-3-arduino-sensores.pdf` — guía de Arduino y sensores (estudiantes).
- `documentos/kits-taller-3-geogreen.pdf` — kits para el Taller 3.

> El **banco de ideas semilla** (proyectos para destrabar equipos) es un recurso transversal del
> programa y vive en `banco-ideas/` en la raíz del repo, no bajo este taller.
