# Banco audiovisual · Taller 3

Material seleccionado para construir el relato visual del Taller 3: evolución de GeoGreen desde
el prototipo físico hasta el diseño 3D y la PCB. Estos archivos son fuentes del futuro PPT; no son
borradores de diapositivas.

Las referencias de fabricantes y documentación técnica —pinouts, vistas de placas, protoboard,
Wokwi y PlatformIO— están organizadas y acreditadas en [`oficiales/README.md`](oficiales/README.md).

Las ilustraciones conceptuales creadas específicamente para la apertura, el sistema GeoGreen, el
desarrollo agéntico, la seguridad y la competencia están documentadas en
[`generadas/README.md`](generadas/README.md).

## Criterio narrativo para el PPT

El relato presenta decisiones, herramientas, pruebas y mejoras realizadas durante la evolución de
GeoGreen. Diego se muestra como responsable de dirigir y validar el proceso técnico. No se utilizará
un encuadre basado en carencias personales como “no sabía usar” una herramienta o componente.

Secuencia visual recomendada:

1. Simulación y programación.
2. Prototipo físico en protoboard.
3. Medición, pantalla y alertas funcionando.
4. Diseño de carcasa 3D y colaboración interdisciplinaria.
5. PCB como etapa de profesionalización del prototipo.
