## Criterio de uso

- Usar el pinout del **UNO R4 WiFi** como referencia principal, porque es la placa física de la
  experiencia GeoGreen.
- Mostrar el pinout del **ESP32** solamente para comparar voltajes, capacidades y cuidados; no
  convertir el taller en una revisión exhaustiva de pines.
- Presentar la protoboard antes del montaje de sensores, destacando continuidad interna y revisión
  previa a conectar USB.
- Utilizar Wokwi y PlatformIO como partes de una misma ruta: **simular → compilar → cargar → probar**.
- Reservar las fotografías, videos y capturas propias de GeoGreen para demostrar el proceso real;
  estas referencias externas explican conceptos y herramientas.
