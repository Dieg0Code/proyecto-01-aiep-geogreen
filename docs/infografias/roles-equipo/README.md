# Serie de responsabilidades del equipo

Colección de seis infografías verticales para los equipos de GeoGreen Escolar
2026. Cada lámina explica una responsabilidad persistente mediante cuatro
preguntas prácticas: cuál es su misión, qué acciones realiza, qué evidencia deja
y qué aporta durante la presentación.

## Láminas

1. `01-coordinacion-geogreen-gptimage.png`: organización del trabajo, acuerdos,
   participación y seguimiento.
2. `02-investigacion-geogreen-gptimage.png`: comprensión del problema, búsqueda
   de información y respaldo de decisiones.
3. `03-diseno-geogreen-gptimage.png`: representación, uso, instalación y mejora
   de la solución.
4. `04-tecnologia-geogreen-gptimage.png`: selección e integración de sensores,
   placa, conexiones, lógica y software.
5. `05-pruebas-evidencia-geogreen-gptimage.png`: seguridad, comprobación,
   mediciones y registro del proceso.
6. `06-comunicacion-geogreen-gptimage.png`: síntesis, soportes visuales, pitch y
   conexión con la audiencia.

## Criterio común

Los roles pueden rotar, pero las responsabilidades no quedan vacías. Cada
integrante lidera una responsabilidad y comprende el proyecto completo. Las
decisiones, la evidencia y los resultados pertenecen al equipo.

## Uso sugerido

- Compartir la colección completa con cada equipo.
- Asignar una lámina inicial a cada integrante.
- Consultarlas al distribuir tareas y revisar avances.
- Recuperarlas antes de organizar el pitch final.
