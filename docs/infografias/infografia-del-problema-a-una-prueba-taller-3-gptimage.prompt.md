# Infografía · Del problema a una prueba · Taller 3

Generada con GPT Image a partir del panorama anonimizado de los nueve productos
recibidos después de los Talleres 1 y 2.

## Propósito

Acortar la cadena de razonamiento que los equipos deben recorrer al comenzar el
Taller 3 y hacer visible el cambio de ritmo:

```text
PROBLEMA → VARIABLE → SENSOR → REGLA → RESPUESTA → EVIDENCIA
```

La pieza no entrega proyectos resueltos ni asigna automáticamente sensores. Usa
como contexto los temas presentes en los trabajos: residuos orgánicos, comida,
compotas, PET, bolsas, cáscaras y envoltorios.

## Prompt

Crear una infografía educativa vertical larga, en español, para estudiantes de
tercero medio de GeoGreen Escolar. Usar identidad visual AIEP–GeoGreen: azul
institucional `#082B5C`, rojo `#D62027`, verde `#2E8B57`, fondo marfil y acentos
dorados. Estilo editorial vectorial, tipografía sans serif grande, flechas claras,
tarjetas redondeadas e iconos mínimos. Sin nombres, grupos, diagnósticos,
calificaciones, fotografías, logotipos inventados ni marcas de agua.

Título: **DEL PROBLEMA A UNA PRUEBA**. Subtítulo: **Ahora cambia el ritmo:
observar → decidir → probar**.

Abrir con el contraste: **YA INVESTIGARON** — residuos orgánicos, comida,
compotas, PET, bolsas, cáscaras y envoltorios — frente a **AHORA TOCA** — convertir
el problema en algo que pueda observarse y comprobarse.

Presentar una ruta vertical de seis pasos:

1. **Aterriza el problema.** ¿Qué ocurre?, ¿dónde?, ¿a quién afecta? Ejemplos:
   envoltorios en el patio, compotas en el gimnasio y comida desperdiciada en el
   casino. Regla: describir una situación observable sin etiquetar personas.
2. **Encuentra la variable.** Nivel, cantidad, presencia, frecuencia, temperatura,
   humedad, luz o apertura. Advertencia: si no pueden nombrar la variable, todavía
   no elijan sensor.
3. **Elige el sensor.** Distancia/nivel → ultrasónico; presencia/conteo →
   infrarrojo; temperatura → sensor térmico; humedad → sensor de humedad; luz →
   fotorresistor; apertura → sensor magnético. Verificar pinout, voltaje, placa y
   seguridad.
4. **Escribe la lógica.** “Cuando [sensor] detecte [condición], entonces [sistema]
   realizará [respuesta]”. Ejemplos: alerta roja al llegar a 80 %; sumar una unidad
   cuando pase un objeto. Sensor observa, regla decide, salida responde.
5. **Haz la prueba más pequeña.** Cambiar una cosa, observar la lectura, definir
   una condición, activar una respuesta y guardar evidencia. Evidencia: foto,
   lectura, video, simulación o error registrado. No construir todo de una vez.
6. **Salida del Taller 3.** Problema concreto, variable observable, sensor
   justificado, regla cuando/entonces, evidencia actual o prueba pendiente y
   próximo hito demostrable.

Cerrar con tres preguntas: ¿el sensor mide realmente la variable?, ¿la respuesta
ayuda a decidir o actuar?, ¿podemos demostrarlo con una prueba? Añadir: **No todos
los problemas necesitan un sensor. Si la tecnología no aporta, vuelvan al
problema.**

Banner final: **UNA IDEA SE VUELVE PROYECTO CUANDO PUEDE PROBARSE.**

Pie: **AIEP OSORNO · GEOGREEN ESCOLAR 2026**.

Priorizar legibilidad móvil, texto exacto, ortografía correcta, jerarquía clara y
espacio en blanco. Evitar tono infantil, castigador, saturado o excesivamente
corporativo.
