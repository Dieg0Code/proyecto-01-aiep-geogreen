# Inventario de componentes AIEP

Documentos de apoyo para reconocer y ordenar componentes disponibles en AIEP para
GeoGreen Escolar.

El inventario corresponde a una **fotografía preliminar tomada el 2 de julio de
2026**. Las cantidades con confianza media deben comprobarse físicamente antes de
armar los kits; no se interpretan como stock confirmado ni como lista definitiva
de compra.

## Archivos

- `inventario-visual-componentes-aiep-geogreen.pdf` — catálogo visual con las fotos
  tomadas en AIEP, explicación simple de qué se ve y uso sugerido.
- `inventario-visual-componentes-aiep-geogreen.tex` — fuente LaTeX del catálogo.
- `inventario-componentes-aiep-2026-07-02.md` — inventario preliminar operativo.
- `assets/` — fotos usadas en el catálogo visual.

## Recompilar

```powershell
tectonic docs\inventario\inventario-visual-componentes-aiep-geogreen.tex --outdir docs\inventario
```
