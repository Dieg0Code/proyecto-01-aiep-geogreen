# Historias de Instagram · GeoGreen Escolar 2026

Piezas públicas en formato vertical `1080 × 1920 px`, preparadas para difusión desde la cuenta
institucional de AIEP Osorno.

## Piezas

- `historia-01-portada.png`: presentación de GeoGreen Escolar 2026.
- `historia-02-programa.png`: ciclo de talleres y mentorías, seguido del evento de presentación
  y premiación.

## Criterio visual

Las piezas toman como referencia el lenguaje observado en las publicaciones de AIEP Osorno:
azul institucional dominante, titulares blancos de alto contraste, acentos rojos, composición
fotográfica editorial, márgenes amplios y uso contenido del texto. GeoGreen incorpora el verde
como acento ambiental secundario.

Los logotipos corresponden al lockup oficial AIEP + Vinculación con el Medio utilizado en las
presentaciones institucionales del proyecto.
