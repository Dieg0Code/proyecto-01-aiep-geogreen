# Estilo AIEP para infografías

## Paleta

- Fondo `#F8F3EC`.
- Navy `#102A43` para títulos, estructura y números.
- Rojo `#D62027` como acento moderado.
- Texto `#243B53` y `#52606D`.
- Bordes `#D8CFC4`.
- Apoyos `#E6EEF7` y `#EDE6DA`.

Usar una proporción aproximada 60/30/10: claros, navy y rojo.

## Composición

- Formato vertical largo `1024x1536`.
- Título fuerte, subtítulo corto y módulos con jerarquía clara.
- Tarjetas blancas con borde fino y aire suficiente.
- Secciones numeradas como anclas visuales.
- Iconografía lineal y diagramas comprensibles.
- Una imagen protagonista por lámina.

## Tono

Institucional, técnico y sobrio, pero cercano y contemporáneo. Sin logos, gradientes ruidosos, estética de startup ni fotografías de stock genéricas.

## Texto

Mantenerlo corto. Revisar ortografía, tildes, ñ, cifras y nombres propios. Si el texto falla, ajustar el prompt y regenerar.
