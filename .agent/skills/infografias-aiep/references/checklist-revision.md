# Checklist de revisión del PNG

## Texto

- [ ] Ortografía, tildes y ñ correctas.
- [ ] Sin palabras deformadas, inventadas, cortadas ni glifos extraños.
- [ ] Nombres, fechas y cifras exactos.
- [ ] Texto grande y legible en teléfono.

## Estilo

- [ ] Fondo claro, navy + rojo en proporción equilibrada.
- [ ] Tarjetas, bordes finos, secciones numeradas y aire.
- [ ] Misma familia visual que las láminas previas.
- [ ] Sin logos, marcas ni watermark.

## Contenido

- [ ] Deriva de la fuente real y no inventa compromisos.
- [ ] Registro correcto para la audiencia.
- [ ] Sin contexto interno ni mensajes meta.
- [ ] Cada sección responde qué muestra, para qué sirve y qué recordar.

## Archivado

- [ ] Nombre `infografia-<tema>-gptimage.png`.
- [ ] Prompt reproducible con el mismo nombre base y `.prompt.md`.
